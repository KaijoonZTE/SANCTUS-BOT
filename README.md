# 👑 S4NCTUS_BOT v1.5.0

Bot de WhatsApp criado por **Neuromancer**

## ✅ Requisitos
- Node.js v16+
- Termux ou VPS Linux

## 📦 Instalação
\`\`\`bash
git clone https://github.com/KaijoonZTE/SANCTUS-BOT.git
cd SANCTUS-BOT
npm install
node index.js
\`\`\`

## 🔑 Conectar
- Digite seu número quando solicitado
- Pegue o código e coloca no WhatsApp
- Menu > Aparelhos conectados > Conectar com número de telefone

## ⚡ Comandos
- /menu — Ver todos os comandos
- /ping — Testar bot
- /menudownloads — Downloads
- /menuzoeira — Zoeira
- /menuadmin — Administração
- /menuia — Inteligência Artificial
